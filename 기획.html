1. 배경 반영 완료

1.1 1주년 모멘텀

NXPC, MapleStory Universe, MapleStory N은 2025년 5월 15일 론칭하여 2026년 5월 15일 1주년을 맞이한다. 1주년 모멘텀에 맞춰 대규모 발표를 진행한다.

1.2 P2E 프레임 탈피의 필요성

현 시점에서 시장은 본 프로젝트를 P2E로 인식하는 경향이 있다. 가시화된 프로덕트가 MapleStory N(블록체인 기반 NFT·토큰 활용 게임)이 전부인 만큼 자연스러운 인식이지만, 이 프레임은 프로젝트의 잠재 가치를 저평가하게 만든다. 다수의 P2E 프로젝트가 실패·러그풀 사례로 누적되며 카테고리 자체의 신뢰도가 하락한 상태이기 때문이다.

본 프로젝트는 블록체인 게임 영역에서 전무후무한 규모의 IP인 MapleStory를 기반으로 한다는 점에서 출발 조건이 다르다. 따라서 P2E 카테고리에 머무르지 않고, 생태계 확장이라는 본래 지향을 명시적으로 드러낼 필요가 있다.

1.3 VIBE IP 개념과 IP의 재정의

1주년 발표의 중심 메시지는 VIBE IP다. 핵심 가설:

  • AI 바이브 코딩으로 게임 창작 비용이 급격히 낮아지면서, 향후 다량의 게임이 시장에 출시되는 '대창작의 시대'가 도래한다.
  • 창작 산출물이 폭증하면 어텐션 경쟁 비용이 치열해진다. 이때 전 세계 2억+ 명이 인지하는 MapleStory 브랜드는 어텐션 측면에서 기초적인 우위를 제공한다.
  • 이 우위만으로는 부족하며, IP 자체를 재정의해야 한다.

IP 재정의 1단계 — 핵심 경험의 스킬화 (1주년 발표 메시지의 본체):

  • 전통적 IP 프랜차이징은 이미지·사운드 에셋 제공과 상업적 활용 허가에 머물러 있었다.
  • 대창작의 시대에는 에셋 제공만으로 부족하다. AI가 활용 가능한 형태로 IP의 핵심 경험을 스킬화해 제공해야 한다.
  • "메이플다움"은 사이드 스크롤·캐릭터 모션 같은 특정 물리적 문법에 한정되지 않는다. 직업·세계관·캐릭터·아이템 체계 등 IP 고유 요소가 잘 살아 있다면 다른 장르(예: 덱빌딩, 턴제 전투)에서도 메이플 색은 충분히 표현된다.
  • 제공해야 할 것은 자연어 명령만으로 IP의 정체성이 즉시 구현되는 개발 환경이다. 코드 블록·로직 단위로 IP 요소를 호출 가능하게 만든다.

IP 재정의 2단계 — MapleStory Passport (5/15 발표에서는 제외):

패스포트는 장기 비전 자산으로 보존하되 5/15 발표·바이브잼 어나운스에서는 메시지에 포함하지 않는다. 헤드라인 명료성 보호 목적.

1.4 바이브 IP 개발 방향 (3축)

  1. 자연어 기반 온체인 IP 라이선싱
  2. 통합 개발 환경 (MCP 기반 스킬·리소스 호출)
  3. 심리스 결제·정산 (온체인 일괄 처리)

이 엔드 투 엔드 구조의 완성에는 시간이 소요된다. 따라서 1주년 발표 이후 비전과 현실의 간극을 채우기 위한 가시적 사례가 필요하다.

1.5 바이브잼의 위치

본 게임잼의 정식 명칭은 바이브잼(VIBE IP Gamejam)이다. VIBE IP 비전의 concrete하고 actionable한 첫 번째 예제로 포장된다. 제작 협업 플랫폼은 NXPC가 투자한 Verse8.

5/15 1주년 발표의 메시지 위계

  1. 헤드라인: VIBE IP 비전 (IP 재정의 1단계)
  2. 헤드라인 직속 증거: 바이브잼 어나운스

5. 구조·트랙 반영 완료

5.1 메이플 IP 색의 표현 정책

특정 장르(사이드 스크롤) 또는 물리적 문법(캐릭터 모션, 발판 레이아웃)을 강제하지 않는다. Verse8 내부 테스트에서 'Slay the Spire' 유사 덱빌딩 게임에 메이플 직업을 투입했을 때 IP 매력이 충분히 살아났음이 확인됐다. 즉 IP 색은 직업·세계관·캐릭터·아이템 체계 등 메이플 고유 요소의 활용도로 측정한다.

5.2 트랙 구성 (확정)

  • 전문가 심사 트랙 — 게임 디자인의 재미·완결성·퀄리티 종합 평가. 내부 심사위원(디렉터·개발실장·기획실장·COO·CEO 등) 선정.
  • 대중성·유저 반응 트랙 — 플레이 수 기준. unique 계정·최소 플레이 시간 검증으로 어뷰징 차단.
  • 잠재력 트랙 (구 아이디어 트랙, 명칭 변경) — 게임잼이 demo 퀄리티 영역인 점을 인정하고, 풀 스케일 개발 시 가능성·잠재능력을 평가. 자세한 metric은 §7.8.

7.7 IP 활용도 평가 (확정 — 단일 축)

요소 개수 카운팅이나 메커니즘 통합도 같은 형식적 측정은 정합한 적용이 어렵다고 판단. 평가의 본질은 "메이플 유저가 이 게임을 메이플로 인식하는가"이므로 단일 정성 축으로 단순화한다.

축배점판단 기준
메이플다움 10점 메이플 유저가 본 게임을 플레이했을 때 "이건 메이플이다"라고 인식하는가, 그 인식이 얼마나 강한가에 대한 정성 평가.
장르·물리적 문법은 무관. 직업·세계관·아이템·캐릭터·세계관 사건 등 어떤 요소를 통해서든 "메이플답다"가 전달되면 된다.
평가자: §7.3 내부 심사위원 5인이 각자 1~10점 부여 후 평균.

모든 트랙(전문가·대중성·잠재력) 평가에 가산점으로 반영. 단일 축이지만 5인 합의 평균으로 개인 편향 완화.

7.8 잠재력 트랙 — Metric 제안 (10명 선정)

게임잼은 본질적으로 demo 퀄리티 영역이다. 잠재력 트랙은 "이 demo를 풀 스케일 게임으로 키웠을 때 사업적·창작적으로 의미 있는 결과가 나올 가능성"을 평가한다. 4축 metric 제안.

축배점판단 기준
